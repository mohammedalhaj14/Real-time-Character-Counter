# ✏️ Real-time Character Counter

A **Real-time Character Counter** web application built using **HTML, CSS, and JavaScript**. It dynamically tracks the number of characters typed into a text area and displays the total count along with the remaining characters.

## 🌟 Features
- 🔥 Live character count updates as you type.
- 🎨 Stylish and responsive UI with CSS.
- ⚡ Performance-optimized with vanilla JavaScript.
- 🛑 Character limit display (default: 500 characters).
- 🔧 Easily customizable for different character limits.
