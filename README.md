# ✏️ Real-time Character Counter

[![Live Demo](https://img.shields.io/badge/TRY%20IT%20NOW-17A2B8?style=for-the-badge&logo=github)](https://mohammedalhaj14.github.io/Real-time-Character-Counter/)

A **Real-time Character Counter** web application built using **HTML, CSS, and vanilla JavaScript**. This lightweight utility dynamically tracks the number of characters typed into a text area and displays the total count along with the remaining characters against a set limit.

## 🚀 Key Features

* **Live Updates:** 🔥 Count updates instantaneously as the user types.
* **Limit Tracking:** 🛑 Displays the total characters entered and the characters remaining (default limit: 500).
* **Performance:** ⚡ Built with vanilla JavaScript for speed and efficiency.
* **Accessibility:** 🎨 Stylish and responsive user interface, easily adaptable to mobile and desktop screens.
* **Customizable:** 🔧 Character limits can be easily modified within the JavaScript file.

---

## 💡 How to Use

1.  Navigate to the **[Live Demo](https://mohammedalhaj14.github.io/Real-time-Character-Counter/)** link above.
2.  Start typing or paste text directly into the input area.
3.  Watch the character count and remaining character display update in real time below the text area.
